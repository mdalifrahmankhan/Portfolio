# Alif — Portfolio

Minimalist, white-first, responsive multi-page portfolio for Alif. Built with semantic HTML, CSS and lightweight JavaScript; no build step or unnecessary backend is required.

## Pages
- Home — `index.html`
- About — `about.html`
- Projects — `projects.html`
- Skills — `skills.html`
- Experience — `experience.html`
- Contact — `contact.html`

## Before publishing
- Replace the email placeholder in `contact.html`.
- Confirm approximate role durations and incomplete work-history details in `experience.html`.
- Add genuine project examples and outcomes; the current project list is clearly labelled as focus areas, not completed case studies.
- Enable GitHub Pages in repository Settings → Pages, using the `main` branch and `/ (root)`.

Design: editorial typography, generous whitespace, restrained olive accents, hairline borders, responsive mobile navigation and reduced-motion support.
